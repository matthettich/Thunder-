# ...Thunder (retired)

...Thunder is now part of **...Thunder Plus**: https://matthettich.github.io/thunder-plus/ (repo `matthettich/thunder-plus`).
It's one app. In Thunder Plus, ⚙ Settings → App → **Mobile** gives you ...Thunder (Synth and Tracker, PAD input,
the …waves and …chains editors hidden). Kits and songs open the same in both setups.

This address now forwards there. Its page and service worker remove the old app's offline copy but leave saved
work in the browser alone; the first time Thunder Plus opens where ...Thunder left a song and kit, it offers to
open them (saving its own song and kit to a project file first), and File → Open ...Thunder's saved work does
the same later.

The app's code up to the merge is in this repo's history (last build: commit 58a0a43, 13 Oct 2026).
